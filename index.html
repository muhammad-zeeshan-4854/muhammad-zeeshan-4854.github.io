Personal project · SaaS

InvoiceHub

A multi-tenant invoicing SaaS I'm building for UK freelancers and small businesses. Each business gets its own isolated workspace to manage customers, raise VAT-correct invoices, email them as PDFs and track what's paid, outstanding and overdue.

  • Multi-tenant architecture: one PostgreSQL database, with EF Core global query filters and save-time guards so no organisation can read or change another's data, proven by integration tests
  • Owner, Admin and Member roles, email verification, password reset, and step-up re-authentication with a separate short-lived token before sensitive screens
  • Server-side UK VAT per line, invoice status workflow, PDF generation with QuestPDF and invoice emails through each organisation's own SMTP account
  • Per-organisation Stripe and SMTP integrations with secrets encrypted using AES-256-GCM, plus "test connection" checks
  • Customer-facing audit log and a developer-only, append-only tracking table protected by PostgreSQL triggers
  • Angular 21 dashboard with Angular Material and ApexCharts: aging report, revenue chart, onboarding checklist, activity feed
  • 48 xUnit test methods, GitHub Actions CI, EF Core migrations generated in CI, and Docker deployment
